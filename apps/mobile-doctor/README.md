# ICare Doctor (Mobile)

Capacitor app for doctors, shipped separately from the patient app. It reuses
`doctor-web` instead of reimplementing the workflow natively — on launch it
loads that site directly.

## Run locally

1. Start `doctor-web` bound to your LAN IP so a phone or emulator can reach
   it (not `127.0.0.1`):

   ```powershell
   npm --workspace apps/doctor-web run dev -- --host 0.0.0.0
   ```

2. Edit `apps/mobile-doctor/www/config.js` with your machine's LAN IP for
   `doctorUrl`.

3. Install Capacitor and generate the native project (first time only):

   ```powershell
   npm install
   npm --workspace apps/mobile-doctor exec cap add android
   npm --workspace apps/mobile-doctor exec cap add ios
   ```

4. Sync and open the native project:

   ```powershell
   npm --workspace apps/mobile-doctor run sync
   npm --workspace apps/mobile-doctor run android
   ```

The `android`/`ios` folders are generated by `cap add` and are not committed
until you run that step locally, since they depend on the native SDKs
installed on your machine.

## Production

Replace `config.js`'s `doctorUrl` with the hosted doctor-web URL (HTTPS)
before building a release.
