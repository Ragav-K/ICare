# Testing Strategy

Required test categories:

- Backend unit, integration, API, authentication, authorization, consent, and audit tests.
- Frontend role workflow tests for healthcare worker, patient, and doctor.
- MATLAB tests for dataset loading, preprocessing, quality checks, inference, evaluation, segmentation, and explainability.
- End-to-end healthcare worker to patient to screening to MATLAB, worker print drafts, patient draft, patient-authorized doctor access by OTP, doctor review, and updated patient report.

Current automated test coverage is only a smoke foundation. Full workflow tests remain pending.
